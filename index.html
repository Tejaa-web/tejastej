UNIT 1

Basics of C++ & Functions (17 Questions)

Q1Procedure Oriented Programming (POP) Languages▶

In Procedure Oriented Programming, a program is divided into small parts called functions or procedures. The focus is on what to do (the steps/logic), not on data.

  • Data moves freely between functions — not very secure.
  • Examples: C, Pascal, FORTRAN
  • Good for small programs, but hard to manage for large ones.
  • If you change one function, it may break others that use the same data.
Think of it like a recipe — a set of steps done one after another.
Q2Object Oriented Programming (OOP)▶

Object Oriented Programming organizes a program around objects (real-world entities) instead of functions.

  • Data and functions are bundled together inside a class.
  • Data is protected (encapsulation) — no outside access without permission.
  • Key concepts: Class, Object, Inheritance, Polymorphism, Encapsulation, Abstraction
  • Examples: C++, Java, Python
Think of a Car as an object — it has properties (color, speed) and behaviors (start, stop).
Q3Role of Objects and Classes in C++▶

Class: A blueprint or template. It defines what properties and behaviors an object will have.

Object: A real instance created from a class.

class Car {         // Blueprint
public:
  string color;
  void start() { }
};
Car myCar;           // Object (real instance)

Classes allow us to model real-world things in code. Objects let us use those models in the program.

Q4Importance of Reusability in OOP▶

Reusability means writing code once and using it again and again without rewriting it.

  • Saves time — don't rewrite the same code.
  • Reduces errors — tested code is reused safely.
  • Easy to maintain — fix in one place, fixed everywhere.
  • Achieved through Inheritance (child class reuses parent class code) and Functions/Classes.
Example: A Vehicle class written once can be reused by Car, Bus, and Truck classes.
Q5Important Features of C++▶
  • Object Oriented — supports classes, objects, inheritance, polymorphism.
  • Fast & Efficient — compiled language, runs very fast.
  • Portable — code can run on different machines.
  • Rich Library — has many built-in functions.
  • Memory Management — new and delete give control over memory.
  • Encapsulation — data hiding using access specifiers.
  • Polymorphism — one name, many forms.
  • Extensible — new features can be added easily.
Q6Iostream Classes in C++▶

The #include <iostream> header provides input/output functionality.

  • cin — reads input from keyboard (input stream)
  • cout — prints output to screen (output stream)
  • cerr — prints error messages (unbuffered)
  • clog — prints log messages (buffered)
#include <iostream>
using namespace std;
int main() {
  int x;
  cin >> x;         // Read from keyboard
  cout << x;        // Print to screen
}
Q7Comments in C++▶

Comments are notes in code that the compiler ignores. They explain what the code does.

  • Single-line comment: starts with //
  • Multi-line comment: starts with /* and ends with */
// This is a single-line comment

/* This is a
   multi-line comment */

int x = 5; // x stores value 5
Comments make code readable for others (and for you later!).
Q8Variable Declaration in C++▶

A variable is a named storage location for data. Before using a variable, you must declare it with a data type.

int age = 20;         // Integer
float marks = 95.5;    // Decimal number
char grade = 'A';     // Single character
string name = "Ravi"; // Text
bool passed = true;   // True/False

Rules: Variable names can't start with numbers, no spaces, can use underscore (_).

Q9Use of const in C++▶

const makes a variable's value fixed (unchangeable) after it's set.

const float PI = 3.14;
PI = 3.5; // ERROR! Cannot change a const
  • Prevents accidental changes to important values.
  • Used for mathematical constants, fixed settings, etc.
  • Makes code safer and easier to understand.
Q10Use of endl in C++▶

endl means end of line — it moves the output cursor to the next line AND flushes the output buffer.

cout << "Hello" << endl;
cout << "World" << endl;
// Output:
// Hello
// World
endl = '\n' (newline) + buffer flush. Use '\n' for speed, endl when you need immediate output.
Q11Importance of new and delete in C++▶

These are used for dynamic memory management — allocating memory during program runtime.

int* ptr = new int;    // Allocate memory for 1 int
*ptr = 42;
delete ptr;            // Free the memory

int* arr = new int[5]; // Array of 5 ints
delete[] arr;          // Free array memory
  • new — requests memory from the heap at runtime.
  • delete — frees that memory to avoid memory leaks.
  • Without delete, memory stays occupied even when not needed.
Q12Program to Explain Simple Functions in C++▶

A function is a reusable block of code that performs a specific task.

#include <iostream>
using namespace std;

int add(int a, int b) {   // Function definition
  return a + b;
}

int main() {
  int result = add(5, 3); // Function call
  cout << "Sum = " << result << endl;
  return 0;
}

Structure: returnType functionName(parameters) { body }

Q13Pass by Value vs Pass by Reference▶

Pass by Value (Call by Value): A copy of the variable is passed. Original is NOT changed.

void change(int x) { x = 100; } // copy changed
int a = 5;
change(a);
cout << a; // Still 5!

Pass by Reference (Call by Reference): The actual variable is passed. Original IS changed.

void change(int &x) { x = 100; } // original changed
int a = 5;
change(a);
cout << a; // Now 100!
Use reference when you want the function to modify the original. Use value when you don't want changes.
Q14Use of Return Statements▶

The return statement sends a value back to where the function was called from.

int square(int n) {
  return n * n;   // Sends result back
}
int result = square(4); // result = 16
  • For void functions, return; just exits the function (no value).
  • The return type must match the function's declared type.
  • A function can have multiple return statements (exits at first one reached).
Q15Default Arguments in Functions▶

Default arguments are values that are automatically used when no argument is provided for a parameter.

void greet(string name = "Guest") {
  cout << "Hello, " << name << endl;
}

greet("Ravi");  // Output: Hello, Ravi
greet();        // Output: Hello, Guest (default used)
Default arguments must be placed at the end of the parameter list.
Q16Concept of Inline Function▶

An inline function is a hint to the compiler to copy the function's code directly where it's called, instead of making an actual function call. This makes it faster.

inline int square(int x) {
  return x * x;
}
  • Reduces the overhead (cost) of function calls.
  • Best for small, frequently used functions.
  • Compiler may ignore the hint for large functions.
Normal function: jump → execute → return. Inline: code copied in place — no jumping!
Q17Scenario: How Functions are Important in Programming▶

Scenario: ATM Machine

An ATM has multiple tasks: check balance, withdraw money, deposit money, print receipt. Without functions, all this code would be one huge messy block. With functions:

void checkBalance() { ... }
void withdrawMoney(int amount) { ... }
void depositMoney(int amount) { ... }
void printReceipt() { ... }

Benefits shown in this scenario:

  • Reusability — checkBalance() is called whenever needed.
  • Easy to fix — if withdrawal has a bug, only fix that function.
  • Readability — code is organized and easy to understand.
  • Teamwork — different team members can write different functions.
UNIT 2

Classes, Objects & Constructors (15 Questions)

Q1Structure of a Class in C++▶
class ClassName {
private:          // Hidden from outside
  int data;

public:           // Accessible from outside
  void setData(int d) { data = d; }
  int  getData() { return data; }
};
  • A class has data members (variables) and member functions (methods).
  • Access is controlled using private, public, protected.
Q2Importance of Member Functions▶

Member functions are functions defined inside a class that operate on the class's data.

  • They access and modify private data (which is hidden from the outside world).
  • They define behaviour of the object (what it can do).
  • They maintain data integrity — data can only be changed in controlled ways.
  • Makes code organized and reusable.
Without member functions, private data would be useless because no one could access it!
Q3Role of Access Specifiers▶

Access specifiers control who can access the members of a class.

  • private — only accessible within the same class. (Default)
  • public — accessible from anywhere in the program.
  • protected — accessible within the class and derived (child) classes.
Think: private = your diary (only you), public = a noticeboard (everyone), protected = family secret (family only).
Q4Concept of Constructors▶

A constructor is a special function that is automatically called when an object is created. It initializes the object's data.

  • Same name as the class.
  • No return type (not even void).
  • Called automatically — you don't call it manually.
class Student {
public:
  string name;
  Student() {               // Constructor
    name = "Unknown";
  }
};
Student s;  // Constructor called here automatically
Q5Parameterized, Copy, and Default Constructors▶

Default Constructor: No parameters. Sets default values.

Student() { name = "Unknown"; }

Parameterized Constructor: Takes arguments to initialize with custom values.

Student(string n) { name = n; }
Student s("Ravi");  // name = "Ravi"

Copy Constructor: Creates a new object as a copy of an existing object.

Student(Student &s2) { name = s2.name; }
Student s1("Ravi");
Student s2(s1);  // s2 is a copy of s1
Q6Constructor Overloading▶

Constructor Overloading means having multiple constructors with the same name but different parameters.

class Box {
public:
  int length, width;
  Box() { length = 0; width = 0; }           // Default
  Box(int l) { length = l; width = l; }         // 1 arg
  Box(int l, int w) { length = l; width = w; }  // 2 args
};

C++ picks the right constructor based on the arguments you pass.

Q7Class Conversion in C++▶

Class conversion means converting an object of one type to another (e.g., from a basic type to a class type, or between class types).

  • Basic → Class: Done using a constructor that takes a basic type as argument.
  • Class → Basic: Done using a conversion function (operator overloading).
class Rupees {
  float amount;
public:
  Rupees(float a) { amount = a; }  // float → Rupees
  operator float() { return amount; } // Rupees → float
};
Q8Manipulation on Private Data Members▶

Private data members cannot be accessed directly from outside the class. They are manipulated using public member functions called getters and setters.

class Student {
private:
  int marks;      // Private — hidden!
public:
  void setMarks(int m) { marks = m; } // Setter
  int  getMarks() { return marks; }   // Getter
};
This protects data from invalid values — e.g., you can check if marks < 0 before setting it.
Q9Relationship Between Object and Memory▶
  • When an object is created, memory is allocated for its data members.
  • Member functions are stored once in memory and shared across all objects.
  • Each object gets its own copy of data, but shares the function code.
  • Objects can be created on Stack (auto-managed) or Heap (using new).
Student s1;           // Stack memory
Student* s2 = new Student(); // Heap memory
delete s2;            // Must free heap memory
Q10Concept of Array▶

An array is a collection of elements of the same data type stored in consecutive memory locations.

int marks[5] = {90, 80, 75, 85, 95};
cout << marks[0]; // 90 (index starts at 0)
  • Access elements using index: array[0], array[1]…
  • Fixed size — cannot grow or shrink.
  • Much easier than creating 5 separate variables!
Q11Concept of Array of Objects▶

Just like an array of integers, we can have an array of objects.

class Student {
public:
  string name;
  int marks;
};

Student class1[3]; // Array of 3 Student objects
class1[0].name = "Ravi";
class1[1].name = "Priya";

Useful for storing multiple instances of the same type — like a list of students, employees, etc.

Q12How Strings Can Be a Data Member▶

A string can be a data member of a class, just like int or float.

#include <string>
class Student {
public:
  string name;   // String as data member
  int rollNo;
  Student(string n, int r) { name = n; rollNo = r; }
};
  • Strings store text like names, addresses, emails.
  • Use the <string> header.
  • Strings can be compared, concatenated, and searched easily.
Q13Importance of Destructors▶

A destructor is a special function that is automatically called when an object is destroyed. It cleans up memory and resources.

  • Same name as the class but with a tilde: ~ClassName()
  • No parameters, no return type.
  • Prevents memory leaks — frees any memory the object was using.
class Student {
public:
  ~Student() {
    cout << "Object destroyed" << endl;
  }
};

Q15Scenario: Constructors in Real-World Applications▶

Scenario: Online Shopping Cart

When a user adds an item to the cart, a CartItem object is created. The constructor sets the item name, price, and quantity automatically.

class CartItem {
public:
  string name;
  float price;
  int qty;

  CartItem(string n, float p, int q) {
    name = n; price = p; qty = q;
  }

CartItem item("Laptop", 55000, 1);

Without constructors, you'd have to manually set every property every time — error-prone and tedious!

UNIT 3

Operator Overloading & Inheritance (9 Questions)

Q1Concept of Operator Overloading — What, Types, Role▶

What is it? Operator overloading means giving new meaning to existing operators (like +, -, ==) when used with objects.

class Distance {
public:
  int meters;
  Distance operator+(Distance d2) {
    Distance result;
    result.meters = meters + d2.meters;
    return result;
  }
};
Distance d1, d2, d3;
d3 = d1 + d2;  // Uses overloaded +

Types of operators that can be overloaded:

  • Arithmetic: +, -, *, /
  • Relational: ==, !=, <, >
  • Unary: ++, --, -
  • Assignment: =
  • I/O: <<, >>

Role: Makes code more natural and readable. Instead of add(d1, d2), you write d1 + d2.

Cannot overload: ::, ., ?:, sizeof
Q2Concept of Inheritance▶

Inheritance allows a child (derived) class to acquire properties and behaviors of a parent (base) class.

class Animal {             // Base class
public:
  void eat() { cout << "Eating"; }
};
class Dog : public Animal { // Derived class
public:
  void bark() { cout << "Woof"; }
};
Dog d;
d.eat();   // Inherited from Animal
d.bark();  // Dog's own method

Promotes code reuse — no need to rewrite common features.

Q3Role of protected Access Specifier in Inheritance▶

protected members are like private, BUT they are accessible in derived (child) classes.

class Animal {
protected:
  int age;   // Protected
};
class Dog : public Animal {
public:
  void show() { cout << age; }  // OK! Child can access
};
Outside code: No access. Child class: Yes access. This is the key role of protected.
Q4Concept of Overriding Member Functions▶

Function overriding means a child class provides its own version of a function that already exists in the parent class.

class Animal {
public:
  void speak() { cout << "Some sound"; }
};
class Dog : public Animal {
public:
  void speak() { cout << "Woof"; } // Override!
};
Dog d;
d.speak(); // Calls Dog's version: "Woof"
Overriding ≠ Overloading. Overriding = same function name in child class. Overloading = same name, different parameters in same class.
Q5Possible Combinations of Inheritance (Single, Multiple, etc.)▶
  • Single: One parent → One child. class B : public A
  • Multiple: Two or more parents → One child. class C : public A, public B
  • Multilevel: A → B → C (chain of inheritance). Grandparent → Parent → Child.
  • Hierarchical: One parent → Multiple children. A → B, A → C
  • Hybrid: Combination of two or more types above.
// Multiple Inheritance
class Father { public: void work() {} };
class Mother { public: void cook() {} };
class Child : public Father, public Mother {};
Q6Hybrid Inheritance and Its Importance▶

Hybrid Inheritance is a mix of two or more types of inheritance in a single program (e.g., Hierarchical + Multiple).

class A {};
class B : public A {};     // Hierarchical
class C : public A {};     // Hierarchical
class D : public B, public C {}; // Multiple

Importance: Models complex real-world relationships. However, it can cause the Diamond Problem (ambiguity when D inherits A twice). Solved using virtual inheritance.

Q7Containership in C++▶

Containership (Has-A relationship): A class contains an object of another class as its data member. This is different from inheritance (Is-A relationship).

class Engine {
public:
  void start() { cout << "Engine started"; }
};
class Car {
  Engine eng;  // Car HAS-A Engine (Containership)
public:
  void drive() { eng.start(); }
};
Inheritance = Dog IS-A Animal. Containership = Car HAS-A Engine.
Q8Concept of Classes Within Classes▶

A nested class is a class defined inside another class.

class Outer {
public:
  class Inner {      // Nested class
  public:
    void display() { cout << "Inner class"; }
  };
};
Outer::Inner obj;
obj.display();
  • Used when Inner class is only relevant inside Outer class.
  • Improves encapsulation and organization.
  • Example: A Node class inside a LinkedList class.
Q9Scenario: Inheritance in Real-World Applications▶

Scenario: Hospital Management System

A hospital has different types of staff: Doctors, Nurses, Admins. All share common properties (name, ID, salary) but have specific behaviors.

class Staff {           // Base class
public:
  string name;
  int id;
  void login() {}
};
class Doctor : public Staff {
public:
  void prescribe() {}   // Doctor-specific
};
class Nurse : public Staff {
public:
  void giveInjection() {} // Nurse-specific
};

Both Doctor and Nurse reuse login() without rewriting it — that's the power of inheritance!

UNIT 4

Polymorphism, Templates & Exception Handling (9 Questions)

Q1Concept of Polymorphism in C++▶

Polymorphism means "many forms" — the same function or operator behaving differently in different situations.

  • Compile-time (Static): Function overloading, Operator overloading — decided at compile time.
  • Run-time (Dynamic): Virtual functions — decided at runtime based on actual object type.
class Shape {
public:
  virtual void draw() { cout << "Shape"; }
};
class Circle : public Shape {
public:
  void draw() { cout << "Circle"; }  // Override
};
Shape* s = new Circle();
s->draw(); // Prints "Circle" — runtime decision!
Q2Concept of Pointers to Objects▶

A pointer to an object stores the memory address of an object, instead of the object itself.

class Student {
public:
  string name = "Ravi";
};

Student s;
Student* ptr = &s;      // Pointer to object
cout << ptr->name;      // Access using -> arrow
  • Use -> to access members through a pointer.
  • Used with new for dynamic object creation.
  • Essential for polymorphism and runtime decisions.
Q3Concept of Virtual Functions▶

A virtual function is a function in the base class declared with the virtual keyword. It allows runtime polymorphism — the correct version is called based on the actual object, not the pointer type.

class Animal {
public:
  virtual void speak() { cout << "..."; }
};
class Dog : public Animal {
public:
  void speak() { cout << "Woof"; }
};
Animal* a = new Dog();
a->speak(); // "Woof" — Dog's version chosen at runtime
Without virtual, the base class version would always be called. With virtual, the correct child version runs.
Q4Virtual Functions and Dynamic Binding▶

Dynamic Binding means the function call is resolved at runtime (not at compile time). Virtual functions enable this.

  • Static Binding: Normal function calls are resolved at compile time — faster but less flexible.
  • Dynamic Binding: Virtual function calls are resolved at runtime using a vtable (virtual table).

The vtable is a hidden lookup table that stores addresses of virtual functions. When a virtual function is called through a pointer, C++ looks up the vtable to find the right function.

Virtual functions + Pointers = Dynamic Binding = Runtime Polymorphism.
Q5The Purpose of this Pointer▶

The this pointer is a special hidden pointer available inside every member function. It points to the current object that called the function.

class Student {
  string name;
public:
  void setName(string name) {
    this->name = name; // 'this->name' = class data member
                        // 'name' = parameter
  }
};
  • Resolves name conflicts between data members and parameters.
  • Used to return the current object from a function (return *this).
  • Used in method chaining.
Q6Concepts of Templates in C++ — Types + Example▶

Templates allow writing generic code that works with any data type. Write once, use for int, float, string, etc.

Types:

1. Function Template:

template <typename T>
T findMax(T a, T b) {
  return (a > b) ? a : b;
}
findMax(3, 7);       // Works for int
findMax(3.5, 1.2);   // Works for float

2. Class Template:

template <typename T>
class Pair {
public:
  T first, second;
  Pair(T a, T b) { first = a; second = b; }
};
Pair<int> p(1, 2);
Pair<string> q("A", "B");
Templates are the foundation of C++ STL (Standard Template Library) — like vector, map, etc.
Q7Concept of Exception Handling in C++▶

Exception handling is a mechanism to handle runtime errors gracefully without crashing the program.

Uses three keywords: try, throw, catch.

try {
  int a = 10, b = 0;
  if (b == 0)
    throw "Division by zero!"; // Throw error
  cout << a / b;
}
catch (const char* e) {
  cout << "Error: " << e;        // Handle error
}
  • try: Code that might cause an error.
  • throw: Signals that an error has occurred.
  • catch: Handles the error.
Q8Use of Multiple Catch Statements▶

A single try block can have multiple catch blocks to handle different types of errors.

try {
  throw 42;         // Throwing an int
}
catch (int e) {
  cout << "Int error: " << e;
}
catch (string e) {
  cout << "String error: " << e;
}
catch (...) {
  cout << "Unknown error";  // Catches everything else
}
  • C++ matches the thrown value type to the correct catch block.
  • catch(...) is a catch-all for any exception type.
  • More specific catches should come before general ones.
Q9Significance of Polymorphism in Modern Programming Languages▶

Polymorphism is one of the most powerful features of modern OOP languages. Its significance:

  • Flexibility — same interface works with different object types. Write one function that handles Circle, Rectangle, Triangle all through a Shape pointer.
  • Extensibility — add new classes without changing existing code. New shape? Just add a new class.
  • Code Reuse — generic code works with many types.
  • Real-world modeling — animals all "speak" but differently; employees all "work" but differently.
  • Framework/Library design — GUI frameworks, game engines, and web frameworks all rely heavily on polymorphism.
Without polymorphism, you'd need a separate function for each type. With polymorphism, one function handles all!
